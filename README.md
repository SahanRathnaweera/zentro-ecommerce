# Zentro

Zentro is a full-stack e-commerce clothing website for Men's, Ladies, and Kids fashion.

## Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, Vite, React Router
**Backend:** Java, Spring Boot, Spring Data JPA, Spring Security, JWT
**Database:** MySQL

## Project Structure

- `frontend/` - the React customer and admin website (coming soon)
- `backend/` - the Spring Boot REST API (coming soon)

## Status

Under development. Built step by step as a learning project.
